Installation Guide

Pawsome & Co. is a static HTML5 + Bootstrap 5 template. No build step or server-side language is required to preview it.

1. File Structure

pet-shop-template/
├── assets/
│   ├── css/  (style.css, dark-mode.css, rtl.css)
│   ├── js/   (main.js)
│   └── images/
├── pages/    (all 14 HTML pages)
├── documentation/
├── index.html   (redirects to pages/index.html)
├── sitemap.xml
└── robots.txt

2. Previewing Locally

Because the pages use relative asset paths (../assets/...), open them through a local web server rather than double-clicking the file, to avoid any browser file:// restrictions:

# From the pet-shop-template folder
python3 -m http.server 8080
# then visit http://localhost:8080/pages/index.html

Any static server (VS Code "Live Server", npx serve, Netlify Dev, etc.) works the same way.

3. Deploying

Upload the entire pet-shop-template folder to any static host (Netlify, Vercel, GitHub Pages, or a standard web server). No build command is needed — the folder is deploy-ready as-is.

4. Dependencies (CDN)

  • Bootstrap 5.3 (CSS & JS bundle)
  • Bootstrap Icons 1.11
  • Google Fonts: Baloo 2 & Inter

All are loaded via CDN in the <head> of every page. For an offline build, download these libraries into assets/ and update the <link>/<script> paths.
